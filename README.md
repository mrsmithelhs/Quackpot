# Quackpot

Quackpot is a public, static browser gacha game used in CourseVGD to help students critically examine microtransaction design by experiencing a fictional duck-collecting game and reviewing an end-of-run Receipt.

The student game has no accounts, telemetry, or runtime network calls. Run state stays in the browser; a student may choose to download a run-usage file and submit it manually. CourseVGD uses Quackpot as an independent project; it is a user of Quackpot, not a dependency.

The canonical design lives in [`docs/founding/design.md`](docs/founding/design.md). Development is underway. The owner accepted Plan 02's local build spike and [repository paths](docs/repo-structure.md); production art, playable mechanisms and live deployment follow their own gates.

**Public-repository privacy rule:** never commit personal information, student data, credentials, analytics keys, or deployment secrets.
