# Quackpot

Quackpot is a public, static browser gacha game used in CourseVGD to help students critically examine microtransaction design by experiencing a fictional duck-collecting game and reviewing an end-of-run Receipt.

Quackpot has no accounts, tracking, network calls, or student data. CourseVGD uses Quackpot as an independent project; it is a user of Quackpot, not a dependency.

The canonical design lives in [`docs/founding/design.md`](docs/founding/design.md). A founding design review is in progress before development begins.

**Public-repository privacy rule:** never commit personal information, student data, credentials, analytics keys, or deployment secrets.
