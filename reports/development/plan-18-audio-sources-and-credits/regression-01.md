## Defect found and fixed by this run
A top-level `__proto__` key was ignored and the file accepted. The validator now scans the whole parsed JSON (bounded depth/size) and rejects `__proto__`, `constructor` and `prototype` anywhere as keys; the case and a nested variant are in the suite.
