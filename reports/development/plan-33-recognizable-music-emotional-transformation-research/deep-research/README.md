# Deep-research results (raw, unverified)

Drop each provider's output here **exactly as produced** — do not edit, reformat or fix citations.

- Prompt A results: `prompt-a/<provider>-<model-or-mode>.md`, e.g. `prompt-a/chatgpt-deep-research.md`, `prompt-a/claude-research.md`, `prompt-a/gemini-deep-research.md`
- Prompt B results: `prompt-b/<provider>-<model-or-mode>.md`
- If a provider returns several parts or a citation list separately, add `-part2`, `-citations`, etc.
- Put the date and the prompt version (the prompts are in `../deep-research-prompts.md`) in the first line you paste or tell the integrator.

Every citation in these files is an **unverified lead** until the integrator (or an authorized worker) opens the source. Verification notes go in `prompt-a/verification.md` / `prompt-b/verification.md`, never into the raw files.

Do not put PDFs of papers in this folder or anywhere in the repository: the repository is public and publisher PDFs are copyrighted. Papers go in a gitignored/excluded holding folder or outside the repo.
