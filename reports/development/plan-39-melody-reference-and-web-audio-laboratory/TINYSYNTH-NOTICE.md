# TinySynth provenance and local modifications

**Current author clarification,2026-10-31:** See author-provenance-clarification.md. The original lead now reports that no upstream runtime or raw instrument tables were retrieved/copied: workers reconstructed recipes from documentation summaries and wrote a custom renderer. Describe current lineage as schema-inspired, worker-authored, not extracted TinySynth tables or the integrated library. The older "reported adaptation" account below is historical and qualified by this clarification. The external transcript audit is the lead's report; root independently read the answer and mechanical comparison, not the full transcripts. Keep the local source pin and reference notices; the upstream comparison revision is not an origin/dependency pin.

The v3 laboratory reports that its procedural GM operator recipes and custom scheduler were adapted from Tatsuya Shinyagaito (g200kg), [webaudio-tinysynth](https://github.com/g200kg/webaudio-tinysynth), under Apache-2.0. The original authoring record in `progress.md` does not identify an upstream commit or exact recipe extraction. Therefore the actual historical upstream revision **cannot be established** from the present evidence. Do not treat a later reference snapshot as proof of that origin or as a dependency pin.

For a reproducible primary-source comparison, upstream `master` resolved on 2026-10-31 to `3d75aee4b3f43cbd932265e7d60201fd5b770397` via `git ls-remote`. The [source at that revision](https://github.com/g200kg/webaudio-tinysynth/blob/3d75aee4b3f43cbd932265e7d60201fd5b770397/webaudio-tinysynth.js) and [README](https://github.com/g200kg/webaudio-tinysynth/blob/3d75aee4b3f43cbd932265e7d60201fd5b770397/README.md) describe its operator format; the [license](https://github.com/g200kg/webaudio-tinysynth/blob/3d75aee4b3f43cbd932265e7d60201fd5b770397/LICENSE) is included locally as `TINYSYNTH-APACHE-2.0.txt` (SHA-256 `b40930bbcf80744c86c46a12bc9da056641d722716c378f5659b9e555ef833e1`). This is a reference revision, not a claim that it was the source used by the prior author. For example, upstream README's piano example differs from the local `GM-00-piano` parameters; local recipes are not asserted to be exact copies.

`lab/patches.js` contains the local operator tables, role mappings, gains and ensemble selections. `lab/synth-engine.js` implements a custom Web Audio graph, scheduling, generated noise, room effect, encoding and export; it does not contain the whole upstream library and is not a drop-in TinySynth implementation. The lab modifies parameter values, gain scaling, envelope and routing behavior and adds its own effects and controls. Existing attribution notices remain in those files; the local Apache license is supplied for redistribution. No upstream audio samples or remote runtime dependency are used.

A concrete comparison against that pinned source: upstream `program1` piano's first operator specifies sine, volume 0.4, decay 0.7, release 0.1; its second specifies triangle, volume 3, decay 0.7, sustain 0.1, routing 1, attack 0.01 and key scale -1.2. Local `GM-00-piano` first operator specifies sine, volume 0.45, decay 0.70, release 0.15 and additional explicit envelope/routing fields; its second specifies triangle, volume 2.8, decay 0.60, sustain 0.02, routing 1, attack 0.01 and key scale -1.2. This single direct comparison establishes a modified recipe relative to the reference snapshot, not the origin or derivation of every program. Exact local program recipes remain in `lab/patches.js`; their individual historical upstream source revisions remain unknown.
