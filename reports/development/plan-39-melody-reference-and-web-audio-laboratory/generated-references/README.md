# Generated music reference drop folder

Place Suno downloads inspired by the Plan 39 M1–M6 melodic references here. This is a local listening and experimentation folder, not a production soundtrack or asset selection. Git ignores everything in this folder except this README and `.gitignore`, including files in subfolders. Git-ignored files are not backed up by the repository; keep a separate copy of anything valuable.

Original filenames are fine. If useful, names such as `M1-paper-toy-v1.mp3` or `M3-bossa-v2.wav` can identify the melodic reference, prompt and attempt. Preserve the actual downloaded extension and the original file.

Optional local notes can record the M1–M6 reference and its export settings, exact prompt, generator and model as shown, date, settings, and favorite passages or timestamps. Those notes are ignored too. Do not include account credentials. Any future reuse, publishing, or production integration is a separate decision; preserve the relevant generation and rights information for review.
