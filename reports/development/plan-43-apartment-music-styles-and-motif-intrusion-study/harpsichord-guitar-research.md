## Shared pluck, different system

A harpsichord uses a plectrum to pluck strings; this [physical-model paper](https://dafx10.iem.at/papers/PerngSmithRossing_DAFx10_P93.pdf) describes the mechanism. Electric guitars also start with plucked vibrating strings, so a simple generic pluck can plausibly evoke either family. That is an inference, not an identification test. In a [harpsichord experiment abstract](https://pubmed.ncbi.nlm.nih.gov/28372146/), plectrum shape changed measured string initial conditions and resulting spectral/decay characteristics on one tested string. Do not generalize that one study to every instrument or claim that brightness alone identifies a harpsichord.

For electric guitar, magnetic pickup position changes how string vibrations are sensed; a [DAFx paper](https://www.dafx17.eca.ed.ac.uk/papers/DAFx17_paper_43.pdf) uses characteristic spectral effects to estimate both pickup and plucking positions. [Aalto's parametric electric-guitar research](https://research.spa.aalto.fi/publications/papers/cmj-electric-guitar-synthesis/) models excitation, pickup response and time-varying string decay, with recorded and synthesized audio examples. This does not prove that a single filter will make our sound recognizable. Clean electric guitar need not involve distortion; amplifier/cabinet character is a separate possible effect.

## What our model actually does

`guitar-pluck.mjs` makes a seeded noise-filled circular delay with averaged-neighbor feedback and a scalar decay, with a fixed 80 ms fade after note-off. `guitar-phrase.mjs` combined mode softens the initial noise and sets decay to .9985. It does **not** explicitly model electric pickup position or electronics, guitar-body resonances, string/fret identities, variable pickup response, pitch bends, vibrato or amplifier/cabinet behavior. Higher octave uses the exact same score transposed +12; mixed-register version uses changed pitches. The prior measured tuning checks and successful deterministic renders do not establish timbre realism. Some missing features may matter, but none has been proven to cause this particular harpsichord impression.

A [Columbia educational project](https://www.ee.columbia.edu/~ronw/dsp/) independently describes an initial simple waveguide sounding like a generic plucked string, then explores more guitar-specific physical modeling; it is a student project and its qualitative outcome is not proof about our audio. A [measured acoustic-guitar comparison](https://euphonics.org/wp-content/uploads/2022/03/Guitar_II.pdf) emphasizes coupled body/string response and frequency-dependent damping. That acoustic-body result is not direct evidence for a solid-body electric guitar. We found no basis for a universal claim that one instrument always has more inharmonicity than the other.
