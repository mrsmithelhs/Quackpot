Four plucked-string sounds in a phrase

Each version plays the same short phrase. The last written notes end around 8.2 seconds; each 11-second file leaves the remaining time for decay and quiet.

Softer attack changes the start of the pluck. Slower decay changes how the string fades while a note is held. Both together combines those two changes. All versions use the same short fade after note-off, so slower decay does not extend the written note.

By default louder players are reduced to roughly align their measured sample peaks. This is not perceptual loudness matching or LUFS; adjust by ear. Raw restores the original playback levels. The WAV files are unchanged.
