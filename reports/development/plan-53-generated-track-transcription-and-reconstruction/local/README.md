# Local transcription workspace

Everything except this guide and the ignore rule is intentionally ignored, including subfolders. Keep original Suno downloads in the existing Plan39 intake; use read-only references/copies here for crops, raw MIDI, corrected events, private input manifests and rendered comparisons. Never put credentials here. Ignored artifacts are not backed up by Git. No generated audio, MIDI or model weights are approved game assets by being present here. Package environments and model caches should use the separately reviewed external locations.
