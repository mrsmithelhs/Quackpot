# Oval contact reconstruction diagnostic

Root-cleared, report-local and exploratory. One finite Node invocation under lane B, with fresh host preflight and ordinary launcher bounds. This is not a production collision policy or a natural race sample.

Use 45 fixed combinations: five locations (straight, bend, straight-to-bend join, bend-to-straight join, finish), three lateral offsets (-5, 0, 5), and three relative velocity cases (closing, grazing, non-closing). Each case starts two entrant centers near one duck diameter apart and uses 0.05 seconds, the selected tick interval. Compare the linear world sweep's predicted contact time with actual separation computed by applying the same locally projected course velocity and reevaluating the oval frame. Evaluate an inclusive fixed 200-subdivision grid as a bounded diagnostic for sampled first penetration, not a proof of earliest root or tangency; retain cases with no sign change. Report linear prediction, separation residual at prediction, first sampled penetration, delay and minimum sampled separation. Finish cases use the common course-length boundary; the study compares geometry and does not assign places. Cases deliberately include geometry that may not be naturally reachable. Record all case IDs, no filtering, maxima, classifications and script/source pins. A finite grid may miss a narrow crossing or tangent; do not infer false-negative rates or adopt an epsilon from it alone.

Refinement v2, specified before rerun: search left-to-right using the conservative speed-derived distance bound, preserve the first interval that cannot be excluded, and continue until an actual inside witness is found. Accept only when that entire possible-first-to-inside bracket is at most 0.000001 seconds; subdivision leaf resolution is 0.0000001 seconds and the cap is 4096 distance evaluations per pair. Return unresolved on an earlier uncertain region wider than the diagnostic bracket, an unobserved tangent, or the evaluation cap. Values are experimental computational parameters, not adopted production precision. Run the same 45 cases and focused tests together in one bounded job; include an analytically known straight closing collision. Original result and comparison are preserved.
