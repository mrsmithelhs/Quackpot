## Proposed arithmetic and boundary semantics

- Canonical authoritative scales: positions, speeds, acceleration and ratings in millionths; time integer microseconds; angles unsigned 2³² turns; CORDIC vectors Q62; BigInt with explicit signed 2¹²⁷−1 bound and ties-to-even signed division. Enforce the input/range/no-progress rules in `protocol.md`; validate every authoritative intermediate and bounded collection, fail unresolved at last validated boundary on limit exhaustion. No decimal float state drives a branch. Constants/table version and serialization version are explicit.
- One control tick is 50,000 µs. Choose each discrete substep as the largest positive integer microsecond not exceeding remaining tick time and a conservative relative-world-travel bound of 250,000 position units (one quarter duck diameter) computed with integer **ceiling** on velocity magnitudes and course-map slope. If the calculated step is <1 µs, stop unresolved as `substep-resolution`; never round up to force movement. Explicit finite per-tick substep/constraint and total event caps are required; pick caps before a run and report if reached. Half-bound sensitivity uses 125,000 units, not seed filtering. This is an explicit sampled physical model, not proof of earliest continuous contact, grazing or tunneling safety.
- At each boundary, sample starting contacts first, then constrain wall/pair in stable ID order. Represent a linearly interpolated motion crossing as the exact rational `(finish−creditedProgress) × 1,000,000 / progressVelocity` microseconds, compare rationals by checked cross multiplication, and retain numerator/denominator as evidence. The integration clock may advance only integer microseconds: floor and ceiling of a nonintegral crossing form a ≤1 µs uncertainty bracket; if another contact/wall boundary can fall inside that bracket, return unresolved rather than infer a favorable order. If no competing boundary exists, advance to the rational crossing state using checked rational interpolation, record the rational time, then continue with the remaining rational interval under the explicit substep cap. Exact same-rational-time contact precedes crossing. Finished entrants cannot later contact. These rational states must remain exact through the boundary, not be rounded to the earlier integer clock and relabeled exact.
- Recompute from each committed boundary after impulse; no stale finish. Candidate correction is capped by the immediately preceding maximum relative sampled travel plus **1,000 millionths of a course unit** (0.001), the existing diagnostic separation margin, with integer checked calculations. It never counts as finish progress, cannot cross corridor or finish or create unvalidated third-party overlap; bounded wall-then-pair passes roll back the entire current boundary on nonconvergence. New injury draws only after valid actual contact, independent per participant, Bounce protected including landing; ongoing contact causes neither fresh event nor draw. Rearm requires both 1.2-unit separation and 0.5 s. The margin is a proposed discrete-model parameter, not an error proof or owner-approved balance; root must approve or amend it before implementation. Bound table error and quantization with finite evidence; no universal certified error or claim of exact historical v1 behavior.
