# Frozen integer race comparison

The source and inputs in `pins.json` are frozen before results. Fixed case order is pair-0, pair-1, pair-2, each control/mixed, plus half-step control for the first two and a named no-injury diagnostic for each. No filtering or new inputs. Node runs three serial seed shards because a single job could exceed its 90-second envelope. Each case executes twice, encodes, strictly decodes, re-encodes identically, tests validly rehashed duplicate identity and unknown field, and tests digest corruption; full canonical result, exceptions and workload are retained. Unresolved results are valid if their structure is valid. Unexpected exception, codec failure, overflow or nonrepeat stops before browser.

One serial isolated Chromium batch uses the same allowlisted snapshot bytes, cases and table, running each case once with the same encode/decode/re-encode and negative checks. Compare exact UTF-8 canonical result and negative exception categories case by case; record first differing byte. Node and browser versions, pin verification, timings, payloads and individual outcomes are retained. No native-float result is used as a canonical reference. Loopback server and isolated profile are bounded by the ordinary launcher, finite readiness, host preflight and cleanup. Artifact equality and strict cleanup verification are separate; sampled cleanup uncertainty requires a qualified nonzero result even if artifacts match. No automatic repeat for uncertain cleanup.

This is report-local experimental evidence only. It does not establish browser/device/accessibility coverage, balance, replay security, production acceptance, or parity with either historical/native resolver.
