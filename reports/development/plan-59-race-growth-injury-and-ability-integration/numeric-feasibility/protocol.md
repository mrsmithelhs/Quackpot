# Integer arithmetic feasibility protocol

Root-cleared report-local experiment, 2026-11-05; no production numeric policy, new dependency or runtime import. The proposed integer state uses millionths of a course unit, integer microseconds, unsigned 2³² turns and BigInt intermediates checked against 2¹²⁷−1. Signed division rounds to nearest, ties to even; angle wrap is modulo 2³². Branches at collision diameter use squared integer distances; equality is explicitly contact in these probes. A zero-duration or non-progressing substep is unresolved, never a forced crossing. Inputs and JSON sizes are bounded; malformed decimal strings, negative zero, overflow and nonfinite inputs are rejected. The 800-tick game watchdog is not reimplemented or validated by this probe.

Reference generation uses Python standard-library Decimal at precision 100, ROUND_HALF_EVEN: Machin π = 16 atan(1/5) − 4 atan(1/239), alternating inverse-power series; atan(1) is π/4, avoiding a slowly convergent x=1 series. Independent Taylor sine/cosine at fixed fractional-turn vectors reduces to [-π,π]. Generate 32 CORDIC angle constants in integer turns and gain-compensation at Q62, plus reference vectors. The generator has no system Math trigonometry or packages. A 32-iteration integer CORDIC at Q62 is experimental; compare it with Decimal references and report observed error, not an unproved universal bound. Canonical data include generator/version/precision and are hashed before use. Existing node bounded launcher applies to finite Python and Node jobs; fresh host preflight and lane B apply to each.

Probes cover signed rounding, wrap, overflow, serialization limits, axes/quadrants and near-wrap, course and contact threshold integers, injury/rest/Down before affine mapping, finish/contact/tie ordering and no-progress guard. Compare fixed vectors with Decimal reference and current native-float values where useful; a different threshold classification is not automatically wrong. Large unexplained geometric error, unsafe crossing or nondeterminism are falsifiers. No full-race parity, Chromium, save/replay, device or production claim follows.
