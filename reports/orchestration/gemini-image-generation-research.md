# Gemini image route — official-source research

Date: 2026-11-04. Read-only research for the owner's requested Antigravity CLI capability experiment; not local execution proof. A separate researcher consulted primary Google material. Interface behavior and models can change; verify the installed route before reuse.

| Evidence | Implication / limit |
|---|---|
| [Antigravity models](https://antigravity.google/docs/models?app=antigravity) describes a separate noncustomizable Nano Banana 2 image tool. | Selecting a Flash reasoning model does not identify the image backend. No displayed update date was recorded. |
| [CLI changelog](https://antigravity.google/changelog?tab=cli), version1.2.16, October3,2026, describes built-in image-generator delegation, result checking with up to three attempts and conversation artifacts. | Supports testing CLI specifically; hidden internal attempts mean two top-level requests are not necessarily two underlying generation calls. |
| [Hooks](https://antigravity.google/docs/hooks/) documents generate_image Prompt/ImageName/optional ImagePaths and artifact metadata. | A native reference-image route is documented; a filename in ordinary prompt text is not equivalent. Actual local file output must be checked independently. |
| [Headless CLI](https://antigravity.google/docs/cli/headless/) documents tool inventories and soft denial when approval cannot be obtained. | Exit0/textual success can coexist with no generated image. Inspect tool events, diagnostics and actual PNG/JPEG bytes. |
| [Google prompting guide, August28,2025](https://developers.googleblog.com/how-to-prompt-gemini-2-5-flash-image-generation-for-the-best-results/) discusses reference edits and descriptive composition/style prompting. | Assign explicit reference roles; use one controlled change and inspect preserved geometry/identity rather than assuming consistency. Older model-specific advice is transferable guidance, not current CLI capability proof. |
| [Current image API guide](https://aistudio.google.com/docs/image-generation) distinguishes image model generations and recommends newer API choices. | Do not silently transfer the newest API backend or features to Antigravity's documented fixed tool. |

Proposed evidence pair: one original layered-paper apartment/desk/rubber-duck bitmap concept with clear space for later HTML UI, followed by a native reference edit changing only afternoon lighting to evening lamp/cool-window light. Inspect actual file type, dimensions/hash, model/tool identity if observable, artifact-copy route and camera/object/style consistency. This is concept usefulness, not SVG suitability, deterministic editing or game integration proof.

Research agent performed no provider generations, installs or repository writes. Requested versus observed identities and local execution belong in the separate probe findings. Private session paths, accounts, raw traces and credentials must not enter committed reports.
