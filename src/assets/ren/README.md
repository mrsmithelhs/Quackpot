# Ren extracted SVG kit

This kit ports existing Plan 41 concept geometry. Plan46 now mounts selected components through focused life views; the kit itself does not read game state, select cosmetics, or implement social rules. The integrated experience remains for owner review. Source pins, selection statuses, gaps and comparison gallery are in `reports/development/plan-45-ren-svg-component-extraction/`.

`renderRen({idPrefix, expression = 'warm', framing = 'bust', decorative = false})` returns `{svg, meta}`. Expressions: `warm`, `laugh`, `tease`, `not-tonight`, `long-day`, `listening`; framing: `avatar` (`46 30 148 148`) or `bust` (`0 0 240 300`). The default is the base appearance with one ear pencil and selected complexion A. No arbitrary combinations of faces, clothes or hair are promised.

`renderRenScene({idPrefix, scene, decorative = false})` returns `{svg, meta}` for `door`, `closed-door` and `couch-close`. Ren’s lower body is cropped by the frame in the two views where Ren appears. The selected closed-door view retains the original wall, light, frame and decorations and adds the owner-selected panel and handle derived from a bounded Haiku candidate; its provenance and comparison are in the Plan46 amendment report. The door includes the owner-selected hand redraw; the couch uses the owner-selected raised placement and framing. `renderFloorCandidate({idPrefix, decorative = false, tv = 'present'})` returns the selected original wide floor composition, with the body edge hidden by the coffee table and static duck supported by the blue magazine. `tv: 'removed'` uses a strictly counted substitution of the existing apartment kit's TV-removed fragment after the pinned floor patch; default output is unchanged and a drifted seam throws. This is a narrow compatibility bridge, not general furniture or wardrobe mixing. The derived close crop remains gallery-only. Context-specific pajama and cardigan looks in these source scenes are not a rotation policy.

`renderRenArrival({idPrefix, look, decorative = false})` returns the two owner-selected box-free doorway variants, `cardigan` and `pajamas`. They preserve the original doorway/face/hair and replace the outfit layers using the selected floor and couch donors; original `door` remains unchanged for the introduction. Stored SVG text has finite runtime drift fingerprints, and the Ren tests pin the exact original/donor/candidate SHA-256 values. Arrival look is chosen and recorded by the social lifecycle, not randomly by this renderer. The authoring and visual comparison record is `reports/development/plan-46-ren-social-lifecycle-integration/arrival-outfit-candidate-brief.md`.

Each instance requires a distinct prefix matching `/^[a-z][a-z0-9-]{0,23}$/`; all other options and values are checked. IDs and Ren classes are isolated per instance. The host must manage clipping and its own cosmetic choice and supply a distinct prefix; this module has no random or mutable state. Do not embed untrusted SVG or text. No report source is imported by runtime modules.

`closed-door.mjs` contains the owner-selected closed-door composition; `source.mjs` contains mechanically extracted round-4 figure definitions and open-door SVG, with CSS classes and IDs made instance-specific during rendering. `scene-patches.mjs` contains localized source-derived additions/replacements to the exact output of the existing apartment kit's living scene; `index.mjs` checks a full-output non-cryptographic drift fingerprint, base length and context around each patch before applying it. It never mutates shared `ROOM_SPECS` or copies the room engine. A full baseline drift comparison is in `ren.test.mjs`; tests also verify the pinned original SHA-256 hashes, exact pre-isolation reconstruction, deterministic options, and instance references. The fingerprint is a drift detector, not an authenticity guarantee; the full pinned-original SHA-256 and equality tests remain necessary whenever apartment dependencies change.

The figures are busts only. Side/turned poses, a full body, a verified gifted-shelf source, flexible independent garment/face combinations and most kept concept variants are not supplied. Owner-dropped bedhead and superseded neck-tattoo/old-door concepts are excluded. Vest v3 and latest dust variants are unreviewed and not silently included. Existing Plan 41 owner/Sonnet artwork is local project concept source; no third-party source was added by this extraction. Consult the Plan 41 provenance and review before any downstream distribution claim.
