# Ren extracted SVG kit (unmounted)

This kit ports existing Plan 41 concept geometry. It does not select cosmetics, read game state, mount a scene, or implement a social interaction. Final visual acceptance remains with the owner. Source pins, selection statuses, gaps and comparison gallery are in `reports/development/plan-45-ren-svg-component-extraction/`.

`renderRen({idPrefix, expression = 'warm', framing = 'bust', decorative = false})` returns `{svg, meta}`. Expressions: `warm`, `laugh`, `tease`, `not-tonight`, `long-day`, `listening`; framing: `avatar` (`46 30 148 148`) or `bust` (`0 0 240 300`). The default is the base appearance with one ear pencil and selected complexion A. No arbitrary combinations of faces, clothes or hair are promised.

`renderRenScene({idPrefix, scene, decorative = false})` returns `{svg, meta}` for `door` and `couch-close`. The lower body is cropped by the door frame or hidden behind the sofa foreground, respectively. `renderFloorCandidate({idPrefix, decorative = false})` returns the original wide unreviewed floor composition for comparison, with the body edge hidden by the coffee table and static duck supported by the blue magazine. The derived close crop is gallery-only, not an accepted composition or this API's production default. Context-specific pajama and cardigan looks in these source scenes are not a rotation policy.

Each instance requires a distinct prefix matching `/^[a-z][a-z0-9-]{0,23}$/`; all other options and values are checked. IDs and Ren classes are isolated per instance. The host must manage clipping and its own cosmetic choice and supply a distinct prefix; this module has no random or mutable state. Do not embed untrusted SVG or text. No report source is imported by runtime modules.

`source.mjs` contains mechanically extracted round-4 figure definitions and door SVG, with CSS classes and IDs made instance-specific during rendering. `scene-patches.mjs` contains localized source-derived additions/replacements to the exact output of the existing apartment kit's living scene; `index.mjs` checks a full-output non-cryptographic drift fingerprint, base length and context around each patch before applying it. It never mutates shared `ROOM_SPECS` or copies the room engine. A full baseline drift comparison is in `ren.test.mjs`; tests also verify the pinned original SHA-256 hashes, exact pre-isolation reconstruction, deterministic options, and instance references. The fingerprint is a drift detector, not an authenticity guarantee; the full pinned-original SHA-256 and equality tests remain necessary whenever apartment dependencies change.

The figures are busts only. Side/turned poses, a full body, a verified gifted-shelf source, flexible independent garment/face combinations and most kept concept variants are not supplied. Owner-dropped bedhead and superseded neck-tattoo/old-door concepts are excluded. Vest v3 and latest dust variants are unreviewed and not silently included. Existing Plan 41 owner/Sonnet artwork is local project concept source; no third-party source was added by this extraction. Consult the Plan 41 provenance and review before any downstream distribution claim.
